# 🏔️ Karjat Trek Guide — Sahyadri Explorer

> Interactive GIS-based web map for trekking, waterfalls, camping & heritage sites in the Karjat–Dahivali region of Maharashtra.

---

## 🗺️ Project Overview

This project is a full-stack GIS web application built for the Karjat region of the Western Ghats (Sahyadri). It integrates **OpenStreetMap data**, **Leaflet.js**, **Flask**, and **OSMnx** to deliver a practical, mobile-friendly tourism and trekking guide.

### Key Features
| Feature | Technology | Description |
|---|---|---|
| Interactive Map | Leaflet.js + CartoDB | Dark-themed, pan/zoom map with OSM base |
| POI Markers | Custom Div Icons | Categorised: Treks, Waterfalls, Camping, Heritage |
| Route Visualisation | Leaflet Polylines | 4 pre-mapped trek routes with difficulty/distance |
| Route Calculator | Haversine formula | Click-to-measure custom routes on the map |
| Seasonal Tips | Flask API | Month-by-month travel advice for the region |
| OSM Data Extraction | OSMnx + Overpass API | Pull live data: trails, peaks, waterfalls, forts |
| REST API | Flask | JSON endpoints for POIs, routes, stats, nearest POI |

## 🚀 Setup & Installation

### 1. Clone / Create the project
```bash
cd karjat-trek-guide
```

### 2. Install Python dependencies
```bash
pip install -r requirements.txt
```

> **Note:** OSMnx installation may take a few minutes as it includes GDAL dependencies.

### 3. Fetch live OSM data (optional but recommended)
```bash
python osm_extractor.py
```
This queries the **Overpass API** to fetch real-time waterfall, peak, heritage, trail, and camping data for the bounding box:
`18.85°N–19.00°N, 73.25°E–73.45°E` (Karjat region)

### 4. Start the Flask server
```bash
python app.py
```
Visit: **http://localhost:5000**

## 🔌 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/pois?category=all` | All points of interest (filter by category) |
| GET | `/api/routes?difficulty=easy` | Trek routes (filter by difficulty) |
| POST | `/api/route-distance` | Calculate distance for custom waypoints |
| GET | `/api/nearest-poi?lat=18.92&lon=73.37` | 3 nearest POIs to a location |
| GET | `/api/seasonal-tips?month=Jan` | Travel tips for a given month |
| GET | `/api/stats` | Summary stats (totals, categories) |

### Example: Route Distance Calculation
```bash
curl -X POST http://localhost:5000/api/route-distance \
  -H "Content-Type: application/json" \
  -d '{"coordinates": [[73.375, 18.920], [73.338, 18.930], [73.302, 18.940]]}'
```

Response:
```json
{
  "total_km": 7.24,
  "segments_km": [3.91, 3.33],
  "estimated_hours": 2.1,
  "estimated_minutes": 124
}
```

## 🛠️ OSM Data Extraction

`osm_extractor.py` uses two approaches:

### Overpass API (no auth required)
Fetches live OSM data for the Karjat bounding box:
- Waterfalls: `waterway=waterfall`, `natural=waterfall`
- Peaks: `natural=peak`, `tourism=viewpoint`
- Heritage: `historic=fort`, `historic=castle`, `historic=ruins`
- Trails: `highway=path` with `sac_scale` difficulty ratings
- Camping: `tourism=camp_site`

### OSMnx Network Analysis
```python
import osmnx as ox

G = ox.graph_from_place("Karjat, Maharashtra, India", network_type="walk")
stats = ox.basic_stats(G)
# → node count, edge count, total path length km, etc.
```
